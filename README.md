# Договор.Онлайн

Веб-сервис учёта и сопровождения договоров на платные образовательные услуги
ЧОУ ВО «Московский университет им. С.Ю. Витте».

Автор: **Курбатов Дмитрий Евгеньевич**, ID 70199902.

Тема ВКР: «Разработка веб-сервиса учёта и сопровождения договоров на платные образовательные услуги университета».

## Стек

- Python 3.9+
- Django 4.2
- SQLite для локального запуска, PostgreSQL через `DATABASE_URL`
- собственная вёрстка без CMS и без готовой темы: стили лежат в static/css/style.css
- openpyxl и python-docx для выгрузок

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Проверка сценариев без браузера:

```bash
python scripts/smoke.py
```

## Что есть в сервисе

- 12 публичных страниц, верхнее меню из 10 пунктов, хлебные крошки на каждой странице
- форма обратной связи
- личный кабинет: заявки, договоры, платежи, документы, профиль
- рабочее место отдела: заявки, реестр, платежи, плательщики, отчёты
- панель администратора: пользователи, программы, новости, обращения, журнал
- хранение сканов в файловой системе
- выгрузка реестра в `.xlsx` и `.docx`
- три роли
